# 승무원 초상화 제작 시안

생성 방식: 내장 이미지 생성 도구.

두 이미지 모두 제작 시안이며 게임 코드에는 연결하지 않았다. 투명 배경, 고정 픽셀 좌표, 동일 파츠의 실제 합성은 아직 검증되지 않았다. 입은 얼굴 바탕에서 분리할 예정이며 현재 얼굴 바탕에는 기존 입이 남아 있다.

## 얼굴 바탕 생성 요청

첨부 이미지는 그림체 참고만 사용한다. 기존 갈색 배경과 시트 배치를 복제하지 말고 새로운 게임용 투명 스프라이트 원본을 만든다. SF 개척 승무원 조합식 흉상 초상화의 FACE BASE만 정확히 6개. 3열 2행의 동일한 정사각형 셀, 위 행은 성인 남성 3종, 아래 행은 성인 여성 3종. 셀마다 동일한 크기, 정확히 정면을 보는 머리, 같은 두개골 폭과 높이, 같은 귀/코/턱/목 위치, 어깨 크기, 동일한 카메라와 조명. 얼굴 윤곽은 각진/긴/둥근 세 종류이되 파츠 호환을 위해 크기 차이는 적게. 30~50대 실무형 승무원. 피부색은 이번 원본에서는 통일한다. 중요: 머리카락, 수염, 눈, 속눈썹, 눈썹, 고글, 장비 장식은 그리지 않는다. 대머리 두개골과 얼굴 피부, 귀, 코, 닫힌 입, 목, 기본 작업복 어깨만 그린다. 눈 영역은 완전히 평평한 피부색으로 비워둔다. 흉상은 쇄골 아래까지. 기본 복장은 공통의 어두운 남색과 먹색 작업복에 작고 탁한 주황 디테일. 전원 복장 동일, 무기 없음. 참고 이미지의 절제된 애니메이션풍을 유지하되 고해상도 일러스트가 아닌 실제 저해상도 픽셀 아트: 각 초상화가 64x64 픽셀을 정수배 확대한 것 같은 단단한 픽셀 덩어리, 제한된 색상, 그림자 2~3단계, 안티앨리어싱과 부드러운 붓질 없음. 각 셀의 여백 포함 위치 기준은 머리 중심 x=50%, 정수리 y=12%, 눈이 나중에 놓일 선 y=40%, 턱 y=68%, 어깨 밑 y=94%. 셀 경계를 넘기지 않는다. 배경은 알파값 0인 진짜 투명이며, 인물 사이 빈 공간도 투명. 배경색, 그라데이션, 빛번짐, 바닥그림자, 바둑판 무늬, 글자, 라벨, 숫자, 테두리, 완성 캐릭터 예시는 절대 추가하지 않는다. 파츠용 얼굴 바탕 6개만 출력.

## 입 표정 생성 요청

첨부된 승무원 시트의 픽셀 아트 그림체, 인물, 작업복, 머리 디자인을 유지하면서 입 표정의 다양성을 보여주는 새로운 컨셉 시트를 제작한다. 전체 4열 3행. 위 2행은 정확히 8개의 분리된 입 파츠: 1 편안한 중립 입술, 2 온화한 아주 옅은 미소, 3 한쪽 입꼬리만 올린 능청스러운 웃음, 4 입꼬리가 살짝 내려간 피곤한 입, 5 짧게 다문 긴장한 입, 6 살짝 삐뚤어진 불만스러운 입, 7 살짝 벌어진 편안한 입, 8 작고 자신 있는 미소. 웃음은 성인다운 절제된 표현, 큰 만화식 입이나 과장된 이빨과 혀는 없음. 각 입 파츠는 동일한 해상도와 크기 범위, 64x64 논리적 초상화에서 입 너비 6~10 픽셀 높이 2~4픽셀 수준의 간결한 픽셀로 표현한다. 입 주변의 피부색 사각형이나 코 턱 얼굴은 그리지 말고 입과 필요한 입술 픽셀만 독립적으로 그린다. 시트에서 비교할 수 있도록 정수배 확대. 아래 한 행은 완성 흉상 4명: 참고 이미지 속 짧은 검은 머리의 남성은 따뜻한 작은 미소, 회색 짧은 곱슬머리 중년 남성은 피곤하고 약간 불만스러운 표정, 검은 단발 여성은 차분하고 편안한 표정, 갈색 묶은머리 여성은 한쪽 입꼬리를 올린 능청스러운 표정. 위 입 파츠에 대응하는 입을 쓰되 눈썹과 눈도 모순되지 않게 최소한으로 조정하여 자연스럽게. 캐릭터를 광대같이 웃기게 만들지 않는다. 작업복과 전반적인 화풍은 참고 시트 유지. 남녀 성인 승무원, 우당탕탕 우주 채취업자 분위기. 인물 모두 독립적으로 서로 겹치지 않음, 전체 간격 충분히 넓게. 배경은 완전히 단색의 차가운 짙은 회색 #20252b, 그라데이션 빛번짐 장식 없음. 이것은 입 파츠와 표정 적용 결과를 비교하는 제작 시안이지 정렬 검증된 최종 게임 스프라이트가 아니다. 글자 라벨 숫자 로고 워터마크 없음. 부드러운 디지털 페인팅 금지, 단단한 픽셀 경계와 제한된 색상, 승인된 참고의 절제된 애니메이션풍 유지.
