# 전투 초상화 표시 시안

내장 이미지 생성 도구로 제작한 정지 화면 시안. 게임 코드에는 미반영. 점멸 동작은 이 이미지에서 검증하지 않았다.

## 생성 요청

게임 UI 수정 시안 한 장. 첫 참고 이미지가 수정 대상 전투 화면이다. 두번째 참고 이미지는 초상화 그림체와 인물 참고다. 16:9 가로 전투 화면. 첫 이미지의 지형, 안개, 작은 분대, 카메라 시점, 상단 임무바, 왼쪽 태세, 오른쪽 미니맵과 지원 버튼 위치는 가능한 한 유지한다. 개선 범위는 하단 승무원 HUD만. 기존 하단의 4개 가로 직사각형 정보창과 이름/레벨/특성/무기명/행동 텍스트 및 긴 조작 안내 문구를 완전히 없앤다. 그 자리에 좌측 하단부터 나란히 같은 크기의 정사각형 픽셀 아트 흉상 초상화 4개를 둔다. 화면 높이의 약 15% 정사각형 초상화, 충분한 일정 간격. 각 초상화 상단 바깥 1줄에 무기 실루엣 + 바로 오른쪽의 탄약 숫자를 그린다. 가장 중요: 무기와 탄약 숫자 뒤에는 어떤 사각형 배경판, 레터박스, 테두리, 캡슐, 카드, 툴팁도 절대로 없다. 전장 위에 직접 떠있는 밝은 회색 무기 실루엣과 흰색 숫자, 아주 얇은 검은 외곽선만. 1번 짧은 검은머리 남성 소총 실루엣 옆 '30 / 120'. 2번 회색머리 남성 산탄총 실루엣 옆 '6 / 40'. 3번 검은 단발 여성 저격총 실루엣 옆 '4 / 32'. 4번 갈색 묶은머리 여성 중화기 실루엣 옆 '0 / 80'. 초상화 얼굴은 두번째 참고의 절제된 애니메이션풍 픽셀 아트. 1번 정상 얼굴, 2번 지친 얼굴과 작은 붕대, 3번 눈감고 중상을 입은 얼굴, 4번 눈감고 부상당한 얼굴. 선정성이나 잔혹함 없음. 초상화에는 HP바만 붙인다. 초상화 아래에 동일한 고정 폭과 높이를 가진 가느다란 HP 표시 딱 한 줄씩: 1번 80% 초록색 연속 바, 2번 60% 주황색 가느다란 수직 분절이 반복되는 바코드형 바, 3번 30% 빨간색 바코드형 바, 4번 30% 빨간색 바코드형 바 오른쪽에 작은 일시정지 기호 두 개의 수직선. 비어 있는 HP 부분은 어두운 회색으로 표시하되 별도 굵은 패널 없음. 모든 HP는 3줄이 아니라 1줄이다. 첫 초상화에만 얇은 금색 선택 테두리, 나머지는 장식 없는 간결한 가장자리. 전체 대원 표시를 감싸는 큰 패널 없음. 오른쪽 하단 지원 버튼과 겹치지 않음. 이 화면에 '정상 중상 이동불능 운반' 같은 설명 라벨이나 디자인 해설, 화살표 주석은 추가하지 않는다. 사진풍, 고해상도 페인팅, 과장된 큰 눈, 새 배경 장식 금지. 원본 게임을 유지하면서 하단만 명확하고 깔끔하게 바뀐 실제 게임 화면 같은 시안.

## 수정 요청

첫 번째 초상화 아래 초록색 체력바만 분절 없는 연속 바로 변경. 주황색과 빨간색 분절 바 유지.
