# 전투 UI 재배치 및 LCD 초상화 시안

내장 이미지 생성 도구 사용. 실제 게임 코드 변경 없음. 생성 이미지의 전장 세부는 원본과 달라질 수 있으며 지형 변경안으로 간주하지 않는다. 배치와 통신 초상화 표현 검토용이다. 화면 효과가 실제로 움직이는 것은 아니다.

검토 사항: LCD 주사선과 금속 베젤이 다소 강하다. 실제 표시 크기에서 얼굴 식별성과 탄약 글자 가독성을 검증해야 한다.

## 생성 요청

첫 참고 이미지는 전투 UI 재설계 대상, 두번째 참고는 인물 얼굴과 픽셀 그림체 참고. 새 16:9 가로 모바일 SF 분대 전투 화면 시안을 만든다. 중앙 게임 필드의 지형 시점과 작은 분대와 어두운 미탐사 영역은 유지한다. 기존 금색 직사각형 패널 중심의 HUD는 완전히 제거하고 전투 가시성을 우선하는 통일된 새 HUD로 바꾼다. 이것은 기능 설명 포스터가 아니라 실제 플레이 화면처럼 보여야 한다. 화면 중앙 75%는 전투 공간으로 비운다. 저해상도 픽셀 기반 산업 SF, 낡은 계측기와 저렴한 장비, 우당탕탕 우주 채취업자. 전체 금색 갈색 UI 금지. 얇은 먹색 금속과 회색, 탁한 청록, 신호용 황색을 쓰고 HP는 초록/주황/빨강으로만 명확히 구분. 강한 네온/홀로그램/매끈한 현대 SaaS 카드/둥근 카드 없음.
상단 왼쪽에는 사각형 패널 없이 작고 읽기 좋은 자원 아이콘과 숫자 '0', 신호 아이콘과 '은밀'만. 불필요한 처치 점수 제거. 상단 중앙에는 가늘고 짧은 임무 스트립 '관측 지점 확보'와 작은 진행 표시 '0%'만. 기존 대형 빈 임무 상자 제거. 오른쪽 위에는 화면 폭 12% 정도의 작고 간결한 사각 미니맵, 얇은 무광 금속 테두리. 필드 가장자리 목표 화살표와 '128m'를 작게 유지.
하단 왼쪽 45% 영역에 대원 4명의 동일 크기 정사각형 통신 LCD 모니터를 한 줄로 배치. 이 요청에서 가장 중요: 초상화는 사진 스티커나 밝은 일러스트 카드를 그대로 붙인 것이 아니라 현장 대원 얼굴을 싸구려 컬러 LCD로 수신하는 모습. 각 모니터는 좁고 얇은 낡은 짙은 회색 베젤, 모서리 0~2px, 화면 자체는 색이 바랜 회녹색 저가형 LCD, 약한 픽셀 격자, 낮은 대비와 제한된 컬러, 옅은 잔상, 작은 신호 끊김 1~2줄. 얼굴 전체를 선명한 녹색 단색으로 만들지 말고 약한 피부색과 머리색이 남아 네 사람을 식별할 수 있게. CRT 볼록 유리나 강한 스캔라인 대신 평평하고 값싼 LCD. 장식 때문에 화면을 작게 만들지 않는다. 첫 남성 짧은 검정 머리 정상, 둘째 회색 곱슬 남성 부상, 셋째 검은 단발 여성 중상, 넷째 갈색 묶은머리 여성 이동불능 운반 중. 두번째 참고에 맞는 얼굴 스타일. 얼굴은 어깨 위 통신 크롭. 첫 선택 모니터에만 얇은 탁한 청록 선택 표시. 이름 레벨 특성 행동 텍스트를 초상화에 덕지덕지 붙이지 않는다.
각 LCD 상단 바깥에 밝은 회색 무기 실루엣과 바로 옆의 탄약 숫자 '30 / 120', '6 / 40', '4 / 32', '0 / 80'을 떠 있게 표시. 총과 탄약을 감싸는 배경 상자/레터박스/카드 없음. 초상화 아래에는 딱 한 줄 HP: 첫째 초록 연속 바 80% 수직 칸 나누지 않음, 둘째 주황 바코드 분절 바 60%, 셋째 빨강 분절 바 30%, 넷째 빨강 분절 바 30%와 작은 일시정지 기호. HP바 길이는 모니터 너비와 일치.
하단 중앙에는 정찰/균형/섬멸 3개를 하나의 간결한 가로 분할 선택 컨트롤로 배치, 작은 눈/방패/조준점 아이콘과 짧은 한글 '정찰', '균형', '섬멸'. 균형만 선택 강조. 세로 좌측 태세 버튼은 완전히 삭제. 터치 가능 크기이되 너무 크지 않게. 하단 오른쪽에는 탄약/의료/지뢰/궤도 폭격을 각각 식별 가능한 픽셀 아이콘 버튼 네 개로 정렬하고 작은 재고 숫자 2,2,1,1만 붙인다. 그 위에는 모듈 투하를 위한 눈에 띄되 간결한 낙하 포드 아이콘 버튼 하나. 모두 군더더기 없는 평평한 산업 장비 스타일. 긴 한글 설명, WASD 등 키보드 조작 가이드, 개별 카드형 도배 없음. 화면의 세 하단 그룹이 서로 겹치지 않도록 폭을 안정적으로 배분하고 바닥 끝에 정렬. 하단 전체에 굵은 불투명 띠를 깔지 말 것. 이 외 새로운 전투 효과나 장식이나 대형 메뉴 추가하지 않음. 실제 전투 화면 시안, 깔끔한 픽셀 정렬과 정보 위계.
